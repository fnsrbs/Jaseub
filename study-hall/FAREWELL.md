# 마지막 날 응원 편지

한국 시간 2026-11-17에 학생이 로그인하거나 기존 세션으로 접속하면 응원 편지를 자동으로 엽니다. 관리자는 자동 표시 대상이 아닙니다. 날짜는 서버 시각으로 보정한 앱 시각을 사용하며, 11월 16일까지는 편지와 다시 보기 버튼을 표시하지 않습니다.

편지를 닫은 뒤 페이지를 이동하거나 출결을 갱신해도 다시 자동으로 열지 않습니다. 다시 로그인하면 다시 표시합니다. 11월 18일부터는 자동으로 열지 않으며 홈의 ‘나의 편지 열기’ 버튼으로 계속 볼 수 있습니다.

개인의 전체 출결 중 퇴실이 완료된 시간을 합산하고, 이용한 날짜는 중복 없이 셉니다. 진행 중인 시간은 제외합니다. 클로버는 기존 본인 snapshot, 왕관·별은 기존 학생 권한의 weekly_ranking 집계를 사용합니다. 수집 조회 실패 시 숫자를 0으로 대체하지 않고 재시도 버튼을 표시합니다. 기록과 수집이 없는 학생도 완주 훈장과 동일한 응원 문구를 볼 수 있습니다. 완주 훈장은 이 편지에 표시하는 기념 훈장이며 기존 순위 수집 개수는 변경하지 않습니다.

응원 문구는 자습실 기록이 12년간의 노력 중 일부임을 알리고, 시험 날짜와 마지막 운영일이 다르므로 ‘시험 날’로 표현합니다. 프런트엔드 배포만 필요하며 DB·Edge Function 변경은 없습니다.

검증: `npm test`, `npm run build`. 날짜 경계, 개인 기록 분리, 시간·일수 합산, 기록 없는 학생, 수집 조회 실패를 `tests/farewell.test.ts`에서 확인합니다.
