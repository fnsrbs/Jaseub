# 마지막 날 응원 편지

기본 설정은 한국 시간 2026-11-17에 학생이 로그인하거나 기존 세션으로 접속하면 응원 편지를 자동으로 엽니다. 관리자는 자동 표시 대상이 아닙니다. 날짜는 서버 시각으로 보정한 앱 시각을 사용하며, 지정한 표시 날짜 전에는 편지와 다시 보기 버튼을 표시하지 않습니다.

편지를 닫은 뒤 페이지를 이동하거나 출결을 갱신해도 다시 자동으로 열지 않습니다. 지정한 날짜에 다시 로그인하면 다시 표시합니다. 다음 날부터는 자동으로 열지 않으며 홈의 ‘나의 편지 열기’ 버튼으로 계속 볼 수 있습니다.

개인의 전체 출결 중 퇴실이 완료된 시간을 합산하고, 이용한 날짜는 중복 없이 셉니다. 진행 중인 시간은 제외합니다. 클로버는 기존 본인 snapshot, 왕관·별은 기존 학생 권한의 weekly_ranking 집계를 사용합니다. 수집 조회 실패 시 숫자를 0으로 대체하지 않고 재시도 버튼을 표시합니다. 기록과 수집이 없는 학생도 완주 훈장과 동일한 응원 문구를 볼 수 있습니다. 완주 훈장은 이 편지에 표시하는 기념 훈장이며 기존 순위 수집 개수는 변경하지 않습니다.

응원 문구는 자습실 기록이 12년간의 노력 중 일부임을 알리고, 시험 날짜와 마지막 운영일이 다르므로 ‘시험 날’로 표현합니다.

관리자 로그인 → 왼쪽 메뉴 **마지막 날 편지**에서 편지를 수정합니다. 운영 대시보드와 운영 설정에도 바로가기가 있습니다. 제목·안내·본문·마지막 응원·훈장 이름과 설명·서명·자동 표시 날짜·학생 표시 여부를 편집하며, 실시간 미리보기와 ‘학생 화면처럼 미리보기’는 날짜와 관계없이 사용할 수 있습니다. 예시 이름과 기록을 명시하며 실제 학생 기록과 혼동하지 않도록 합니다. 기본 편지 불러오기는 편집 내용만 바꾸고, ‘편지 저장’을 눌러야 반영됩니다.

설정은 기존 `settings.site_copy` 안의 `farewell_*` 문자열 필드로 저장합니다. 기존 관리자 전용 `site_copy` API를 재사용하고 `20261116032957_editable_farewell_letter.sql`에서 부분 저장·날짜/타입/길이 검증을 추가합니다. 로그인 문구 저장과 편지 저장은 서로의 항목을 덮어쓰지 않습니다. 저장 감사 기록을 보존하며 함수 실행은 기존과 같이 service_role에만 허용하고 관리자 신원을 확인합니다. Edge Function 재배포 없이 DB 마이그레이션과 프런트엔드 배포가 필요합니다.

검증: `npm test`, `npm run build`. 날짜 경계, 개인 기록 분리, 시간·일수 합산, 기록 없는 학생, 수집 조회 실패를 `tests/farewell.test.ts`에서 확인합니다. 편지 수정·날짜 변경·표시 중지·입력 검증·관리자 권한·부분 저장 보존·감사 기록은 `tests/farewell-editor.test.ts`에서 확인합니다.
