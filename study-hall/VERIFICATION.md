## 계정 또는 기기 설정 후 확인할 항목

- 소유자가 직접 설정한 교사 비밀번호로 정상 로그인, gateway의 IP 위변조 방지 최종 확인. 비밀번호는 에이전트가 수집하지 않음.
- 실제 휴대폰 카메라 권한 허용/거부 및 카메라 없는 기기의 안내, 현장 QR 스캔. 카메라 하드웨어/권한 테스트는 미실행.
- 운영 DB 백업·복구 연습. 공식 문서에 기반한 절차 제공, 미실행.

PGlite는 PostgreSQL의 단일 엔진을 사용하므로 단위 검증의 Promise 병렬 호출은 실제 여러 연결 사이의 경합 검증과 다릅니다. 이를 보완하여 실제 Supabase에 임시 학생을 만든 뒤 동시 HTTP 요청을 별도로 실행했습니다. Edge 단위 테스트는 외부 Auth와 DB 연결을 모킹하며 실제 서버 검증과 구분합니다. 데모 브라우저 시연은 실제 DB 연결 검증으로 계산하지 않습니다.

- 고정 QR 추가: 27개 테스트 통과. Vault 영구 보관, 반복 조회 동일 토큰, 교사 전용 조회·재발급, 이전 QR 무효화 검증. 운영 DB에서도 지속성·학생 RPC 접근 차단 확인.
- 좌석 참고 시트 적용: 6열 × 12줄, 좌우 역순 번호, 세 구역 통로, 출입문·교탁·운동장 방향. 운영 DB 72석 좌표와 배정 보존 테스트 확인.

- 교사 조회 전용 코드와 확인된 성별 관리 추가: 전체 30개 테스트와 빌드 통과. 교사 로그인·조회 범위·쓰기 차단·코드 재발급·로그아웃·세션 만료·직접 RPC/테이블 접근 차단 검증.

- 성별 등록 폼 및 5자리 코드: 남자·여자·미확인 원자적 저장, 성별 누락 시 기존 값 보존, 잘못된 값 거부, 코드 형식·현재 코드 중복 방지·소문자 로그인·재발급 접근 폐기 테스트 추가.

- 학생 코드 관리자 조회·재발급 일치·권한 차단, 학생 삭제 시 입실 중 거부·세션 폐기·좌석 해제·출결 보존, 출결 기록 삭제의 사유 필수·관리자 권한·삭제 전 감사 데이터 보관 검증.

- 로그인 문구 6항목의 공개 읽기, 관리자만 저장, 항목·문자열·길이 검사와 변경 이력 검증. 30개 테스트 및 빌드 통과.

- 2026-10-15 좌석 배치도 선택·동성 짝 추첨·누적 경고카드: 34개 테스트 및 빌드 통과. 69명(남18·여51) 무작위 추첨, 고정/미선택 자리 유지, 불가능한 동성 짝 배정 거부, 서버 트랜잭션 롤백 검증. 경고카드 사유 필수·중복 재전송 방지·관리자만 발급·교사 전체 읽기·학생 본인 범위·직접 테이블/RPC 차단 확인. 가상 브라우저에서 좌석 선택 토글과 짝 추첨 미리보기, 경고카드 2장 누적 및 새로고침 보존 확인. 실제 학생에게 테스트 카드 발급 또는 좌석 변경 없음.

- 좌석 성별 색상(남 파랑·여 분홍)과 범례·텍스트를 표시. 경고카드 삭제는 관리자 권한·삭제 사유 검증·재전송 멱등성·누적 제외·교사/학생 범위·원본/감사 이력 보존을 PGlite에서 확인.
