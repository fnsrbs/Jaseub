# 구글 좌석표 반영

학생 관리의 `구글 출석부에서 새 학생 불러오기`도 동일한 연결을 사용합니다. `출석부(확정)`의 B열 학번·C열 이름을 읽어 학번이 없는 학생만 추가하고 5자리 코드를 발급합니다. 기존 학생과 삭제한 학생은 수정·복원하지 않습니다. 새 학생은 성별 미확인·좌석 미배정 상태이며 학생 목록에서 수정하고 코드를 확인할 수 있습니다. 구글 출석부 자체는 변경하지 않습니다. 이전 버전 스크립트를 배포했다면 연결 코드를 다시 복사해 웹 앱을 새 버전으로 업데이트해야 합니다.

관리자 좌석 관리에서 `구글 시트 연결 설정`을 열어 최초 1회 연결합니다.

1. `연결 코드 준비`를 누르고 코드를 복사합니다.
2. Google Apps Script 새 프로젝트의 Code.gs를 해당 코드로 교체합니다.
3. 웹 앱으로 배포합니다. 실행 사용자는 본인, 액세스는 모든 사용자로 설정하고 Google 권한을 승인합니다.
4. 웹 앱의 `/exec` URL을 앱에 입력해 `연결 확인 및 저장`합니다. 연결 검사는 시트를 수정하지 않습니다.

연결 후 배정을 확정하고 `구글 시트에 반영`을 누르면 서버에 저장된 배정을 보냅니다. 미확정 미리보기는 전송하지 않습니다. 좌석표의 72개 학번·이름 칸만 갱신하며 빈자리는 비웁니다. 해당 칸의 기존 표시 수식은 값으로 바뀌며, 원래 수식·값은 관리자 감사 이력에 보관합니다. 원본 명단과 다른 시트는 수정하지 않습니다.

연결 코드는 관리자 전용이며 서명 비밀값을 포함하므로 공개 저장소에 올리지 않습니다. 서버가 Vault의 비밀값으로 요청에 서명하고 스크립트가 서명·시각·중복 요청·대상 시트를 검증합니다. 학생과 교사 뷰어는 연결 설정과 반영 기능을 사용할 수 없습니다.

Edge Function 배포 시 `index.ts`, `seat-sheet-script.ts`, `seat-sheet-sync.ts`를 함께 업로드해야 합니다. Google 연결 전에는 버튼이 비활성화됩니다. 데모 모드는 실제 Google 시트를 변경하지 않습니다.
